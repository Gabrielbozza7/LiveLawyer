# LiveLawyer Repository

## Initial Setup

When you are first setting up the repository to work with your computer, you should visit these guides in the following order:

1. [GitHub SSH Key Setup](./docs/github_ssh_key_setup.md)
2. [VPN Setup](./docs/vpn_setup.md)
3. [Registering for External Services](./docs/registering_for_external_services.md)
4. [Repository and Dev Container Setup](./docs/repository_and_dev_container_setup.md)
5. [Environment Variables Setup](./docs/environment_variables_setup.md)
6. [EAS Setup and Usage](./docs/eas_setup_and_usage.md)

You might also want to take a look at [Guidelines](./docs/guidelines.md), [Future Development Roadmap](./docs/future_development_roadmap.md), and [Supabase Information](./docs/supabase_information.md), but those are not part of the initial setup process.
